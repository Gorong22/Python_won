### 1. feed.js 수정 사항

#### 🔴 Critical 문제 해결

**1.1 이미지 로드 중복 실행 방지**

- **문제**: `loadFeedImages()`가 여러 번 호출될 수 있어 메모리 누수 발생
- **해결**: `isFeedImagesLoading` 플래그 추가로 중복 실행 방지
- **위치**: 50-118줄
- **코드 변경**:

  ```javascript
  // 수정 전: 중복 실행 방지 없음
  function loadFeedImages() { ... }

  // 수정 후: 중복 실행 방지 플래그 추가
  let isFeedImagesLoading = false;
  function loadFeedImages() {
    if (isFeedImagesLoading) return;
    isFeedImagesLoading = true;
    try { ... } finally { isFeedImagesLoading = false; }
  }
  ```

**1.2 스크롤 이벤트 리스너 중복 등록 방지**

- **문제**: `initSliderDotsSync()`가 중복 호출되어 리스너 누적
- **해결**: `WeakSet`을 사용하여 이미 리스너가 등록된 슬라이더는 스킵
- **위치**: 123-212줄
- **코드 변경**:

  ```javascript
  // 수정 전: 중복 등록 가능
  function initSliderDotsSync() {
    sliders.forEach((slider) => {
      slider.addEventListener("scroll", ...); // 매번 등록
    });
  }

  // 수정 후: 중복 등록 방지
  let sliderListenersAttached = new WeakSet();
  function initSliderDotsSync() {
    sliders.forEach((slider) => {
      if (sliderListenersAttached.has(slider)) return; // 이미 등록됨
      sliderListenersAttached.add(slider);
      slider.addEventListener("scroll", ..., { passive: true }); // 한 번만 등록
    });
  }
  ```

**1.3 DOMContentLoaded 중복 리스너 통합**

- **문제**: 동일 파일 내에서 DOMContentLoaded가 2번 등록됨 (4줄, 386줄)
- **해결**: 하나의 리스너로 통합하여 중복 실행 방지
- **위치**: 4줄과 386줄 → 하나로 통합
- **코드 변경**:

  ```javascript

  window.addEventListener("DOMContentLoaded", () => { ... }); // 4줄
  document.addEventListener("DOMContentLoaded", () => { ... }); // 386줄

  // 수정 후: 1개의 통합 리스너
  window.addEventListener("DOMContentLoaded", () => {
    // 모든 초기화 로직 통합
  });
  ```

**1.5 프로토콜 URL 자동 보정**

- **문제**: 프로토콜 상대 URL(`//`)이 모바일에서 불안정하게 해석됨
- **해결**: `normalizeImageUrl()` 함수로 자동 보정
- **위치**: 7-14줄
- **코드 변경**:

  ```javascript
  // 수정 전
  img.src = `${CDN_BASE}${fileName}`; // "//ecimg..."

  // 수정 후
  function normalizeImageUrl(url) {
    if (url.startsWith("//")) {
      return window.location.protocol + url; // "https://ecimg..."
    }
    return url;
  }
  ```

**1.6 이미지 로드 에러 재시도 로직**

- **문제**: 네트워크 오류 시 재시도 없이 이미지가 영구적으로 깨짐
- **해결**: `loadImageWithRetry()` 함수로 최대 2회 재시도
- **위치**: 16-35줄
- **코드 변경**:

      };

### 2. community.js 수정 사항

#### 🔴 Critical 문제 해결

**2.1 innerHTML 전체 재생성 제거**

- **문제**: `innerHTML = ""` 후 `innerHTML +=`로 재생성하여 메모리 누수 및 대량 reflow 발생
- **해결**: `DocumentFragment`를 사용하여 메모리 효율적으로 DOM 생성
- **위치**: 109-174줄
- **코드 변경**:

  ```javascript
  // 수정 전: innerHTML 사용
  function renderPosts(filter = "전체") {
    postList.innerHTML = ""; // 전체 DOM 삭제
    filteredPosts.forEach((post) => {
      postList.innerHTML += `...`; // 문자열 연결로 재생성
    });
  }

  // 수정 후: DocumentFragment 사용
  function renderPosts(filter = "전체") {
    // 기존 DOM 안전하게 제거
    while (postList.firstChild) {
      postList.removeChild(postList.firstChild);
    }

    const fragment = document.createDocumentFragment();
    filteredPosts.forEach((post) => {
      const article = document.createElement("article");
      // ... DOM 요소 생성
      fragment.appendChild(article);
    });
    postList.appendChild(fragment); // 한 번에 추가하여 reflow 최소화
  }
  ```

**2.2 프로토콜 URL 자동 보정**

- **문제**: 동일한 프로토콜 상대 URL 문제
- **해결**: `normalizeImageUrl()` 함수 추가
- **위치**: 47-54줄

**2.3 DOMContentLoaded 중복 리스너 통합**

- **문제**: 192줄과 358줄, 629줄에 중복 리스너
- **해결**: 하나의 리스너로 통합
- **위치**: 192줄로 통합
