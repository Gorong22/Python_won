# 통합 Taxonomy 시각화 다이어그램

## 전체 아키텍처 개요

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         통합 Taxonomy 시스템                             │
└─────────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    │               │               │
                    ▼               ▼               ▼
        ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
        │  작가 입력    │  │  독자 입력    │  │  추천 엔진    │
        └───────────────┘  └───────────────┘  └───────────────┘
                │                   │                   │
                │                   │                   │
                ▼                   ▼                   ▼
        ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
        │ genre_scores  │  │  user_tastes  │  │  Cosine       │
        │  (0.0~1.0)    │  │   (0~100)     │  │  Similarity   │
        └───────────────┘  └───────────────┘  └───────────────┘
                │                   │                   │
                └───────────────────┴───────────────────┘
                                    │
                                    ▼
                        ┌───────────────────────┐
                        │   추천 결과 (작품)     │
                        └───────────────────────┘
```

## Taxonomy 계층 구조

```
Level 1: Canonical Genres (고정 5개)
├── fantasy    [판타지]
├── action     [액션]
├── daily      [일상]
├── thriller   [스릴러]
└── comedy     [코미디]

Level 2: Sub-tags (스토리 요소, 분위기 등)
│
├── Story Elements (스토리 요소)
│   ├── reincarnation [환생] → fantasy:0.85, action:0.20, ...
│   ├── regression [회귀] → fantasy:0.80, action:0.30, ...
│   ├── transmigration [빙의] → fantasy:0.75, daily:0.40, ...
│   └── ...
│
├── Mood (분위기)
│   ├── happy-ending [해피엔딩] → fantasy:0.60, daily:0.70, ...
│   ├── slow-burn [슬로우 번] → daily:0.80, fantasy:0.50, ...
│   └── ...
│
├── Character (캐릭터)
│   ├── strong-female-lead [강한 여주] → fantasy:0.70, action:0.80, ...
│   ├── tsundere [츤데레] → daily:0.60, comedy:0.70, ...
│   └── ...
│
└── Setting (배경)
    ├── school-life [학원물] → daily:0.80, comedy:0.60, ...
    ├── office-romance [직장 로맨스] → daily:0.70, fantasy:0.30, ...
    └── ...
```

## 데이터 변환 흐름 (상세)

### 작가 입력 → genre_scores

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 작가 UI 입력                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  장르 선택 (1~2개):                                         │
│  ☑ fantasy                                                  │
│  ☑ romance                                                  │
│                                                             │
│  태그 선택 (0~10개):                                        │
│  ☑ 환생                                                     │
│  ☑ 회귀                                                     │
│  ☑ 빙의                                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 2: Taxonomy 매핑                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  장르 매핑:                                                 │
│  "fantasy" → fantasy (canonical)                           │
│  "romance" → fantasy (canonical, 매핑 규칙)                │
│                                                             │
│  태그 매핑:                                                 │
│  "환생" → reincarnation (sub-tag)                          │
│  "회귀" → regression (sub-tag)                             │
│  "빙의" → transmigration (sub-tag)                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 3: genre_scores 계산                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 초기화: { fantasy: 0, action: 0, daily: 0, ... }        │
│                                                             │
│  2. 장르 직접 점수 (가중치 0.6):                             │
│     fantasy: +0.6                                           │
│                                                             │
│  3. 태그 가중치 누적 (가중치 0.4):                           │
│     "환생" → fantasy: +0.34, action: +0.08, ...            │
│     "회귀" → fantasy: +0.32, action: +0.12, ...              │
│     "빙의" → fantasy: +0.30, daily: +0.16, ...              │
│                                                             │
│  4. 합계:                                                   │
│     fantasy: 0.6 + 0.34 + 0.32 + 0.30 = 1.56               │
│     action: 0 + 0.08 + 0.12 + 0.04 = 0.24                  │
│     daily: 0 + 0.04 + 0.06 + 0.16 = 0.26                    │
│     ...                                                     │
│                                                             │
│  5. 정규화 (최대값 1.56로 나눔):                             │
│     fantasy: 1.0                                            │
│     action: 0.15                                            │
│     daily: 0.17                                             │
│     thriller: 0.06                                           │
│     comedy: 0.14                                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 4: DB 저장                                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  works 테이블:                                              │
│  {                                                          │
│    genre: ["fantasy", "romance"],  // 원본 (UI 호환)        │
│    tags: ["환생", "회귀", "빙의"],  // 원본 (UI 호환)        │
│    genre_scores: {  // ← 추천 엔진용                        │
│      fantasy: 1.0,                                          │
│      action: 0.15,                                          │
│      daily: 0.17,                                           │
│      thriller: 0.06,                                        │
│      comedy: 0.14                                           │
│    }                                                        │
│  }                                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 독자 입력 → user_tastes

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 독자 UI 입력                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  장르 선택 (다중):                                          │
│  ☑ fantasy                                                  │
│  ☑ slice-of-life                                            │
│                                                             │
│  취향 선택 (다중):                                          │
│  ☑ 환생                                                     │
│  ☑ 해피엔딩                                                 │
│  ☑ 강한 여주                                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 2: Taxonomy 매핑                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  장르 매핑:                                                 │
│  "fantasy" → fantasy (canonical)                           │
│  "slice-of-life" → daily (canonical)                       │
│                                                             │
│  취향 매핑 (sub-tag와 동일):                                │
│  "환생" → reincarnation                                    │
│  "해피엔딩" → happy-ending                                  │
│  "강한 여주" → strong-female-lead                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 3: user_tastes 계산                                     │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 초기화: { fantasy: 50, action: 50, daily: 50, ... }     │
│                                                             │
│  2. 장르 직접 점수:                                         │
│     fantasy: 80 (선택됨)                                    │
│     daily: 80 (slice-of-life → daily)                       │
│     action: 20 (선택 안됨)                                  │
│     thriller: 20 (선택 안됨)                                │
│     comedy: 20 (선택 안됨)                                  │
│                                                             │
│  3. 취향 가중치 조정 (+30점):                                │
│     "환생" → fantasy: +25.5, action: +6, ...                │
│     "해피엔딩" → fantasy: +18, daily: +21, ...              │
│     "강한 여주" → fantasy: +21, action: +24, ...            │
│                                                             │
│  4. 합계:                                                   │
│     fantasy: 80 + 25.5 + 18 + 21 = 144.5 → 100 (최대값)    │
│     action: 20 + 6 + 3 + 24 = 53                           │
│     daily: 80 + 3 + 21 + 9 = 113 → 100 (최대값)            │
│     thriller: 20 + 1.5 + 1.5 + 12 = 35                     │
│     comedy: 20 + 4.5 + 12 + 6 = 42.5                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 4: DB 저장                                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  readers 테이블:                                            │
│  {                                                          │
│    preferredGenres: [...],  // 원본 (하위 호환)             │
│    preferredTastes: [...],  // 원본 (하위 호환)             │
│    user_tastes: {  // ← 추천 엔진용                        │
│      fantasy: 100,                                          │
│      action: 53,                                            │
│      daily: 100,                                            │
│      thriller: 35,                                          │
│      comedy: 42                                             │
│    }                                                        │
│  }                                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 추천 엔진 매칭 과정

```
┌─────────────────────────────────────────────────────────────┐
│ 독자 A의 user_tastes                                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  {                                                          │
│    fantasy: 100,                                            │
│    action: 53,                                              │
│    daily: 100,                                              │
│    thriller: 35,                                            │
│    comedy: 42                                               │
│  }                                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            │ Cosine Similarity
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 작품 B의 genre_scores                                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  {                                                          │
│    fantasy: 0.85,                                           │
│    action: 0.15,                                            │
│    daily: 0.17,                                             │
│    thriller: 0.06,                                          │
│    comedy: 0.14                                              │
│  }                                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│ 유사도 계산                                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  dot_product =                                              │
│    100×0.85 + 53×0.15 + 100×0.17 + 35×0.06 + 42×0.14       │
│    = 85 + 7.95 + 17 + 2.1 + 5.88                           │
│    = 118.93                                                 │
│                                                             │
│  magnitude_user =                                            │
│    √(100² + 53² + 100² + 35² + 42²)                         │
│    = √(10000 + 2809 + 10000 + 1225 + 1764)                  │
│    = √25898 ≈ 160.93                                        │
│                                                             │
│  magnitude_work =                                           │
│    √(0.85² + 0.15² + 0.17² + 0.06² + 0.14²)                 │
│    = √(0.7225 + 0.0225 + 0.0289 + 0.0036 + 0.0196)          │
│    = √0.7971 ≈ 0.89                                         │
│                                                             │
│  similarity = 118.93 / (160.93 × 0.89)                       │
│            = 118.93 / 143.23                                │
│            ≈ 0.83 (83%)                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
                    높은 유사도 → 추천!
```

## 핵심 포인트 요약

1. **통일된 언어**: 작가와 독자가 같은 Taxonomy를 사용
2. **자동 변환**: UI 입력이 자동으로 추천 벡터로 변환
3. **하위 호환성**: 기존 필드는 유지, 새로운 필드 추가
4. **확장 가능**: Sub-tag 추가는 쉽지만, Genre 축은 고정
5. **명확한 매핑**: 모든 UI 값이 canonical genre로 명확히 매핑됨
